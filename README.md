# John Johnson’s Portfolio

Personal portfolio website showcasing projects and a long-form case study for **Checkout Rush**.

## Pages

- **Home** (`index.html`) — Hero, featured project, skills, activities, contact
- **Projects** (`projects.html`) — Project grid with links
- **Case Study** (`case-study.html`) — Full narrative: problem, solution, process, tech, testing, results, walkthrough video

## Featured project

**Checkout Rush** — 3D grocery checkout simulator for early money math.

- [Play the game](https://checkoutrush.netlify.app/)
- [Read the case study](case-study.html)
- [View source](https://github.com/NATcodakid/Checkout-Rush)

## Run locally

Clone the repo and open `index.html` in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8080
```

The layout is responsive (fluid type, flexible spacing, scroll-synced case study table of contents) with reduced-motion support.

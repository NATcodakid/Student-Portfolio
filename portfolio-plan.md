Section 5: Your Educational Game Project
Project Title
Checkout Rush

One-Line Description
A 3D grocery store checkout simulator that teaches kids how to add prices, count money, and make correct change under the fun pressure of a moving customer line.

The Problem It Solves
Many younger students understand money better when they can see it and use it in a realistic situation, but worksheets do not always make the skill feel connected to real life. Checkout Rush helps students practice adding prices, counting bills and coins, and giving change in a game environment that feels active and memorable. It is designed for kids ages 7-9 who are learning early money math and need repeated practice without feeling like they are only doing drills.

How It Works
The player becomes a cashier in a busy 3D grocery store. A customer walks up with items, the player scans the items, reads the total, sees how much money the customer gives them, and selects the correct bills and coins to return as change. The difficulty scales across Easy, Medium, and Hard bands, so players start with simpler amounts and work up to trickier mixed coins and bill combinations with totals up to $50.

Impact / Results
Number of playtesters: 6 elementary students, mostly grades 2-4
Average play session: 10-12 minutes
Key finding: Players stayed engaged longer when the math was connected to a cashier role, and the game format made repeated practice feel less like homework.
Best user quote: "Wait, this is math? I thought we were just playing the store game."
What I Learned
Building Checkout Rush taught me how much planning goes into making a game feel simple for the player. I learned how to connect 3D visuals, JavaScript game logic, money calculations, sound feedback, and user testing into one working project. I also learned that educational games need to be tested with real learners because the parts that seem obvious to the developer are not always obvious to younger players. The biggest lesson was that a good learning game has to respect both sides: it needs to teach the skill clearly and still be fun enough that students want to keep playing.
